# press-release-intel
Funding Intelligence Pipeline

Automated press-release intelligence that turns noisy funding announcements into grounded, structured B2B leads.

Open the live funding dashboard

Overview

Funding Intelligence Pipeline is an end-to-end system for finding sales and market-intelligence signals inside public press releases. It continuously collects releases from wire services, identifies genuine capital-raising announcements, extracts structured deal data with Claude, verifies core facts against the source text, and publishes the resulting leads to a live terminal-style dashboard.

The project was built around a practical problem: funding announcements are valuable buying signals, but manually reviewing high-volume wire feeds is slow and unreliable. This pipeline converts that unstructured stream into searchable, source-linked records while treating an honest missing value as safer than a convincing hallucination.
